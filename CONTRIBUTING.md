# Contributing to the showcase

Product feedback, documentation corrections, and accessibility observations are welcome through Issues or focused pull requests.

Describe the business task, expected behavior, and relevant public documentation. Use synthetic examples. Do not include credentials, customer documents, private application code, database exports, or sensitive incident details.

This repository accepts improvements to public showcase materials. It is not the private application's source repository, and a public issue is not a commercial support agreement. Proposals do not imply a delivery commitment.

Only submit material you are entitled to share. Maintainers may request revisions to keep contributions within the showcase's scope and license. No access to the private platform is granted by contributing.

Run `python3 scripts/verify_showcase.py` before proposing a change. If adding or removing a file, update `PUBLIC_FILES.txt` and explain why the file belongs in the public showcase. Never solve an allowlist failure by copying private source or runtime data into this repository.

Communicate respectfully, focus criticism on ideas and behavior, and respect privacy. Maintainers may close or remove harassment, spam, unsafe disclosures, or off-topic submissions.

For security concerns, use the private reporting route in [SECURITY.md](SECURITY.md).
