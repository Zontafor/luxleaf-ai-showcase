# Security reporting

This repository contains public showcase materials. It does not host the LuxLeaf application, customer data, or a public inference service.

For a suspected credential disclosure, sensitive-data exposure, or a security concern about these materials, use [GitHub's private vulnerability reporting form](https://github.com/Zontafor/luxleaf-ai-showcase/security/advisories/new). Do not post credentials, customer content, or exploit details in a public issue.

Include the affected public URL or file, a concise description, and safe reproduction steps. Share only the minimum necessary information. Do not access other people's data, test third-party services without permission, or send live secrets as proof.

There is no published response-time commitment or bug-bounty program. This development showcase makes no production security or compliance certification claim. For documentation corrections that do not contain sensitive information, use a regular issue.
